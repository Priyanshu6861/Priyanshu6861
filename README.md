## 🎯 About Me

I am a passionate **Backend & Full-Stack Software Engineer** specializing in the **Shopware 6** and **Symfony** ecosystems. With deep expertise in eCommerce architectures, ERP integrations, and asynchronous messaging pipelines, I build robust, high-performance web applications that scale seamlessly under heavy traffic.

- 🛍️ **Shopware 6 Specialist**: Expert in custom plugin development, DAL extensions, Rule Builder, cart/checkout decoration, and admin panel modules (Vue 3/Meteor).
- ⚡ **Event-Driven Architecture**: Designing asynchronous workflows with **RabbitMQ**, message consumers, and scheduled background workers.
- 🔍 **Search & Performance Optimization**: Implementing high-speed search with **Elasticsearch / OpenSearch**, HTTP cache fine-tuning, and database query optimization.
- 🌐 **Modern Frontend & Headless**: Building fast, headless storefronts and modern web applications with **Next.js**, **React**, and **TypeScript**.
- 📐 **Clean Code Advocate**: Strict adherent to **PSR-12**, static analysis (**PHPStan**), strict typing (`declare(strict_types=1)`), and maintainable software architecture.
